# Welcome to the archive of all my challenges !

You will find here all the challenges I've made for different CTFs (Capture The Flag) I have contributed to.

Feel free to use them as you want! All I ask in return is to be credited.

*Make sure to use a different name for each challenge if you don't want your users to find this repo!*

This repo is organized by challenge category. For each category you will find a contents page to help you find what you want.<br>
All challenges are structured the same way.
- [X] challenges.md that explains the challenge, how to solve it, how to make it yourself, and so on.
- [X] Files of the challenge, if there are any.
- [X] Files to create the challenge. I try my best to include a program, tool, or whatever I used to create it so you can use it to make your own version.
